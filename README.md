# ThisIsNotALMS

A web application for managing attendance workflows for lecturers and students.

## Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Install dependencies
```bash
npm install
```

### Run locally
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

- Frontend stack: React + TypeScript + Vite
- Styling: Tailwind CSS
- Backend services: Firebase
