Instructor Notes
📝 Pedagogical Notes for the Instructor
  • Common misconception: Students often use INT for phone numbers or postal codes — address this explicitly and explain why VARCHAR is correct (leading zeros, special characters).
  • Live coding tip: Make intentional errors (e.g., forget NOT NULL) and fix them live — models debugging behaviour and reduces student anxiety about mistakes.
  • Accessibility: Provide SQL code snippets on the shared Teams document for students who have difficulty typing quickly.
  • Extension task: Fast finishers can explore ALTER TABLE to add columns to their existing table.
  • Platform note: Confirm all students can access YooBees SQL Programming deck before Session 2 begins.
