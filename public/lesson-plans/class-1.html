Instructor Notes
📝 Pedagogical Notes for the Instructor
  • Inclusivity: Provide VMs or cloud MySQL access for students without admin rights on personal devices.
  • Pacing: MySQL installation can run over time — prioritise connectivity over full setup; students can complete at home using YooBees video tutorials.
  • Prior knowledge: Some students may have Excel experience — validate this and use it as a bridge to DBMS concepts.
  • Differentiation: Fast finishers can run CREATE DATABASE test_db; and explore MySQL Workbench schema view as an extension activity.
  • Next class preview: Ensure all students have working MySQL before Class 2 — SQL Programming requires the environment.
