SESSION 2 — Aggregations, DML & Introduction to JOINs
12:00 – 12:20
20 min
Mini-Lecture — Aggregate Functions, UPDATE & DELETE
  • Aggregate functions: COUNT(*), COUNT(col), SUM, AVG, MAX, MIN — when to use each
  • GROUP BY: "How many students enrolled per year?" — conceptual model of grouping
  • HAVING: filtering after aggregation (vs. WHERE which filters before)
  • UPDATE syntax: UPDATE table SET col=val WHERE condition; — importance of WHERE
  • DELETE: DELETE FROM table WHERE condition; — never run without WHERE in production
  • Safety tip: run SELECT first to preview rows that will be affected

Instructor Notes
📝 Pedagogical Notes for the Instructor
  • Critical safety point: Always emphasise UPDATE and DELETE without WHERE are dangerous — demonstrate the consequence on a test table live.
  • HAVING vs WHERE: This is a classic misconception. Draw the SQL execution order on the board: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
  • Jigsaw logistics: Pre-assign expert groups before class. Use groups of 5 so each function has one expert per mixed team.
  • JOIN depth: Keep JOINs introductory today — students will practise deeply in the SQL Practice Lab. Avoid overwhelming with LEFT/RIGHT/FULL OUTER in one session.
  • Differentiation: Early finishers can attempt RIGHT JOIN and FULL OUTER JOIN as extension challenges.
