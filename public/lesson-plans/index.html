  • MySQL Community Server installation and first connection

Class 2 · SQL DDL
SQL Programming Fundamentals
DDL commands, data types & basic data retrieval
  • SQL categories: DDL, DML, DCL, TCL overview
  • CREATE DATABASE, CREATE TABLE with constraints and data types
  • INSERT INTO (single and multiple rows)
  • SELECT with column projection; DESCRIBE and SHOW TABLES

Class 3 · Advanced SQL
Advanced SQL Queries & Data Manipulation
Filtering, sorting, aggregations, JOINs & DML
  • WHERE clause with comparison, logical, LIKE, IN, BETWEEN operators
  • ORDER BY, LIMIT, OFFSET — sorting and pagination
  • COUNT, SUM, AVG, MAX, MIN with GROUP BY and HAVING
  • UPDATE, DELETE (with safety), INNER JOIN introduction
Query Olympics Jigsaw Retrieval Practice Open Plan →
4
Class 4 · ER Design
Entity-Relationship Diagrams — Foundations
Chen's notation, entities, attributes, relationships & cardinality
  • ER diagrams as visual blueprints; Chen's notation symbols
  • Attribute types: simple, composite, multivalued, derived, key
  • Cardinality: 1:1, 1:N, M:N with real-world examples
  • Group design challenge + Gallery Walk with peer feedback
Gallery Walk Socratic Method Group Design Open Plan →
5
Class 5 · Advanced ER
Advanced ER Concepts & Participation Constraints
Weak entities, composite/multivalued attributes, total vs. partial participation
  • Weak entities (double rectangle) and identifying relationships (double diamond)
  • Composite attributes, multivalued attributes (double ellipse), derived attributes
  • Total vs. partial participation constraints — notation and meaning
  • Hospital Management System case study + Online Shopping ER design
Case-Based Annotation Activity Peer Teaching Open Plan →
6
Class 6 · Schema Mapping
ER to Relational Schema Mapping
All 8 mapping rules — from conceptual design to SQL schema
  • Rules 1–4: Strong entity, weak entity, binary 1:1 and 1:N mapping
  • Rules 5–8: M:N relationship tables, multivalued attributes, ternary, composite
  • Group mapping activity using own Class 4 ER diagrams
  • Peer assessment with 8-rule checklist; ER Knowledge Check quiz (20 MCQ)
Worked Examples Peer Assessment ER Quiz Open Plan →
7
Class 7 · Normalization
Database Normalization & Functional Dependencies
1NF, 2NF, 3NF, BCNF — designing anomaly-free schemas
  • Anomaly discovery: insertion, deletion, update anomalies
  • Functional dependencies: full, partial, transitive
  • 1NF (atomic values), 2NF (no partial deps), 3NF (no transitive deps)
  • BCNF + Socratic seminar: normalisation vs. denormalisation trade-offs
