Building Blocks
MySQL Data Types
Every column in a table must have a data type — it tells MySQL what kind of value to expect.
INT
Whole numbers
e.g. 1, 25, 1000
FLOAT / DECIMAL
Decimal numbers
e.g. 3.14, 99.99
BIGINT
Very large whole numbers
e.g. 9,223,372,036…
VARCHAR(n)
Text up to n characters
e.g. 'Alice', 'Hello'
TEXT
Long text (no length limit)
e.g. blog post content
CHAR(n)
Fixed-length text
e.g. country codes 'MY'
DATE
Calendar date
e.g. '2024-09-01'
DATETIME
Date + time combined
e.g. '2024-09-01 09:30:00'
BOOLEAN
True or False (1 or 0)
e.g. is_active = TRUE

Command 1 of 5
Creating Databases & Tables
Step 1 — Create a Database
CREATE DATABASE school_db;
USE school_db;
Step 2 — Create a Table
CREATE TABLE students (
  id      INT AUTO_INCREMENT PRIMARY KEY,
  name    VARCHAR(100),
  age     INT,
  email   VARCHAR(150),
  gpa     DECIMAL(3,2)
);
🔑 Key Concepts
  • PRIMARY KEY— unique identifier for each row
  • AUTO_INCREMENT— MySQL auto-assigns the next number
  • VARCHAR(n)— text up to n characters
  • DECIMAL(3,2)— 3 digits, 2 after decimal (e.g. 3.75)
Result — empty table created

Inserting Data
Syntax
INSERT INTO table_name
  (column1, column2, ...)
VALUES
  (value1, value2, ...);
Example — Insert 3 students
INSERT INTO students (name, age, email, gpa)
VALUES
  ('Alice', 20, 'alice@uni.edu', 3.80),
  ('Bob',   22, 'bob@uni.edu',  3.50),
  ('Carol', 21, 'carol@uni.edu',3.90);
Anatomy of INSERT
INSERT INTO which table to add rows to
(columns) which columns you're filling
VALUES the actual data — match column order!

Filtering
Filtering with WHERE
Syntax
SELECT columns
FROM table
WHERE condition;
Examples
-- students older than 20
SELECT * FROM students
WHERE age > 20;

-- find a specific student
SELECT * FROM students
WHERE name = 'Alice';

-- multiple conditions
SELECT * FROM students
WHERE age > 20 AND gpa >= 3.70;
Comparison Operators

!= not equal
> greater than
< less than

Sorting
Sorting with ORDER BY
Syntax
SELECT columns
FROM table
ORDER BY column ASC|DESC;
Examples
-- highest GPA first
SELECT * FROM students
ORDER BY gpa DESC;

-- alphabetical by name
SELECT * FROM students
ORDER BY name ASC;

-- combined with WHERE + LIMIT
SELECT * FROM students
WHERE age > 20
ORDER BY gpa DESC LIMIT 10;
ASC
Ascending (default)
smallest → largest
1  →  2  →  3
A  →  B  →  C
DESC
Descending
largest → smallest
3  →  2  →  1
C  →  B  →  A
ORDER BY gpa DESC

Updating Records
Syntax
UPDATE table
SET column1 = new_value
WHERE condition;
Examples
-- Bob got a better grade!
UPDATE students
SET gpa = 3.75
WHERE id = 2;

-- Update multiple columns

SET age = 23, email = 'bob.new@uni.edu'

⚠️ DELETE vs TRUNCATE
DELETE FROM t WHERE … — removes specific rows
DELETE FROM t — removes all rows (slow)
TRUNCATE TABLE t — wipes all rows instantly, resets IDs

Going Further
Aggregate Functions
Perform calculations across many rows and return a single result.
-- count all students
SELECT COUNT(*) FROM students;

-- average GPA
SELECT AVG(gpa) FROM students;

-- highest and lowest GPA
SELECT MAX(gpa), MIN(gpa)
FROM students;

-- group by + count
SELECT age, COUNT(*) AS total
FROM students
GROUP BY age;
COUNT()
Counts number of rows
→ 3
